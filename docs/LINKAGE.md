# 液压方向与精细建造

选中液压杆后，只需选择“收缩 50%”或“伸展 50%”。初始长度为 L 时，目标分别为 0.5L 或 1.5L；动作结束后恢复初始姿态。不再提供建造时缩短/伸长液压杆、开启角或行程百分比微调按钮。初始长度由两端节点的位置决定，需要改变安装长度时移动节点。

选择方向会保存对应的长度驱动设置，相关连杆进入运动求解；其他不冲突的液压杆保留自动开桥。收缩/伸展方向支持撤销、重做、保存和加载。旧存档中已有的负/正行程，加载时分别转换为 -50%/+50%，保持方向；磁盘文件只在玩家保存时更新。

几何锁死、死点、力不足、桥叶或船只净空不足仍会停止动作并显示原因；50% 是目标行程，不代表任何结构都能无条件达到。下方三角形参与整体联动求解，但普通钢梁和桥面不会任意改变长度，岸边支座不会移动。

建造网格和拖动吸附统一为 0.25 米，节点最小间距和构件最短建造长度也为 0.25 米。网格显示 0.25 米细分，1 米主线较明显。吸附已有节点的范围缩小到 0.1 米，拖动时排除自身；预览和松手使用相同规则。节点球和拾取半径已相应缩小，避免相邻细分节点重叠、点错。

同一非锚点桥面接缝连接两根液压杆时，运行时自动建立左右独立端点，闭合传力、开启分离，避免对侧支撑锁死本侧驱动。真实锚点、桥墩、旧桥保护规则继续生效。场景仅显示颜色诊断，长提示在紧凑提示卡内滚动查看。

通用连杆目前支持二维准静态铰接组件，有规模限制；钢索和立柱组件仍会明确提示不支持。玩家旧桥和旧存档不会被静默改动初始几何。

测试命令：`dotnet run --project Tests/BridgeTests`。

## 三角形极限与显示

活动桥的机构位移和弹性位移均按真实比例显示，测试、失败快照和回放使用同一规则。静态桥仍支持变形放大。此前放大弹性位移会在接近共线死点时，把本来只有几厘米的挠度放大成米级的杆长变化外观。

驱动三角形按三条边的目标长度检查三角不等式，并在继续运动将使三角形趋于共线时停在上一个可接受姿态。采用无量纲两倍面积与两条最长边乘积之比 0.075 作为接近死点的保守保护阈值；只阻止进一步恶化的姿态，允许反向回位。该阈值是游戏的运动保护，不是材料强度或构件断裂判据。

节点运动速度上限为 3 m/s；接近高传动比的位置时通过减小本次驱动进度减速，而非改变普通杆长或跳到另一装配姿态。目标仍为收缩/伸展 50%，受阻时不会假报完全开启。已有力限制、失稳检测、车辆和船只等待继续生效。

当前回归桥的液压杆 #137 与钢梁 #136、#104 构成三角形，两根钢梁约为 6.708 m 和 2.693 m。液压边必须大于约 4.016 m；从约 5.025 m 收缩 50% 后仅 2.512 m，不可能保持其余两边长度并完成动作。应调整安装节点或铰接拓扑，使整个目标轨迹保持可行并避开共线位置；添加随动杆本身不能消除这一几何限制。

## 列车出场

列车按车头位置从左侧引道出场，不再用整列车的最后一根轴反推车头出生位置；汽车保留既有出发位置。列车前后悬长按其模型参考点计算，后车按车身尾端保持距离，车尾驶离出口后才算通过。长列车尚未进入存储路径的车厢沿左岸水平地面向后延伸，不会堆在路径起点；道路中断的另一端仍不允许越过断口行驶。

## 船只与提前开合

船只按事件速度航行，不再等桥。控制器逐帧根据船头到达时间、机构剩余开启时间、解锁时间、已进入活动段的车辆清空时间提前停止新车进入并开桥；船尾通过后关桥，连续船只的开启窗口自然合并。不能实现的机构或来不及开启的桥仍会发生实际碰撞，不会暂停船只掩盖问题。

船体、甲板、舱室、驾驶室窗、烟囱的尺寸与偏移来自同一个 ShipGeometry 数据源，渲染和碰撞共享；碰撞考虑各部分沿河道的实际位置，船头上方的空处不再被当作整船最高点。构件以两侧桁架或桥面实际宽度参与空间相交检查。自动岸边驱动优先于内部液压子桥段，避免“内部驱动数量较多”挤掉主驱动，并且不会再把对侧液压杆当作刚性阻挡支撑诊断。

## 刚性拆分点

新执行的中点拆分会保存原构件端点和分段比例。新点显示为蓝色方块，区别于普通球形节点；拆分完成提示和属性面板注明“刚性连接、不可折叠”。它可随原构件运动，但不能单独拖成折角，也不能改成开合锁扣。通用运动求解保持其在原构件直线上的比例，结构求解保留此处的弯矩传递；相连半段断裂后不允许继续用隐藏刚性约束驱动。节点类型支持保存、加载、撤销和重做。旧存档里没有此信息的普通节点不会按外观猜测并转换，需重新拆分才能记录刚性来源。

## 多液压杆联合机构

当主桥叶内部还有液压杆时，运行时自动把主驱动和内部驱动纳入同一个长度约束求解。主桥叶保留刚体形状，内部驱动的从动段通过实际连接节点转动；液压杆两端可以同时移动，不要求其中一端固定在岸上。已有方向设置优先，自动补入的驱动默认收缩 50%；自动关联只影响测试副本，不重写玩家存档。

诊断改用实际运行控制器结果，避免把独立桥叶识别失败时的“删掉内部钢梁”建议用于联合机构。普通钢梁不缩短，内部支撑不删除；驱动力、死点、断裂、交通和回位锁定检查继续生效。联合运动并不保证任意布局都能完成 50% 目标：当前回归桥约完成 66.25% 的目标进度（实际收缩约 33.125%）后遇到几何极限，未假报完全开启；模型实际净空允许船只通过，随后可以回位。可行串联机构另有两根液压杆完整 50% 行程及回程的回归测试。
