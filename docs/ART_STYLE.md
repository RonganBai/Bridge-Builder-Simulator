# 低面数载具与关卡环境

载具保留各自的道路行驶与车轴参考点。轿车增加车门、窗柱、门把手、格栅与号牌；货车及厢车增加踏板、格栅、货箱门铰链、反光条与挡泥板；公交车增加窗柱、侧条与后部通风口；坦克增加侧裙装甲、发动机格栅、观察口与天线；列车增加机车侧通风口、登车踏板、货车加强筋与色带；行人增加手臂、帽子和背包。车身垂直范围归一到车辆定义高度，保持实际通行净高。

船只增加甲板栏杆、舱窗、货物和烟囱饰带。船只部件通过共享的 ShipGeometry 与 ShipSolid 数据生成模型及碰撞几何。

所有新增细节使用简单盒体、低分段圆柱或球体。载具各节按材质合并网格，场景静态装饰也按材质批处理。GPU 预览统计：轿车924面、货车1272面、公交936面、坦克2448面、四节列车约5300面、厢车1008面、满载重卡1272面、15人队伍4440面。所有车辆高度均经过实际模型包围盒校验。

每关分别配置地表、土层、树叶、点缀、水面和天空颜色。装饰位置使用稳定散列种子；建筑与树木留出道路和建造操作区域。侧视建造时仍沿用现有装饰显隐规则。

高架引道原本位于道路中心的单柱改为两侧双柱门架。柱中心位于Z=±3.2m，柱宽0.8m；基础深度1.2m，最窄净宽5.2m。第九关下层车道宽4m，桥墩和基础均在车道之外，横梁位于上层桥面下方。此处调整的是环境引道桥墩，没有更改玩家桥梁方案。

验证包含完整模拟测试、Godot C#构建、Forward+实机渲染、模型包围盒与面数检查，以及第九关实际生成桥墩的车道侵入检查。


## 曲面和缺面修复

坦克履带使用16段闭合环形带和逐段履带板；轿车前后挡风玻璃使用6段曲面并贴合斜面驾驶舱，车体与车顶采用圆角轮廓；火车头使用分段弧形侧轮廓与倾斜挡风玻璃；船首与船底使用共同定义的凸多面体，模型和SAT碰撞检测使用相同顶点及面。

网格合批前把每个输入网格转换为索引网格，防止自建曲面与已有基础几何混合时丢失三角面。合并前后检查实际面数，如不一致则保留原网格显示，避免悬浮车灯、驾驶室缺面。程序化三角形统一正面绕序，并重新进行了Forward+渲染检查。

## 新增车型

数值为游戏内通行配置，质量包括对应载荷；车轴载荷比例合计为1。超长重卡定位为低速特种运输。

半挂的车头和挂车分别沿道路定位，各车轴按实际偏移加载。超长半挂按车头从左岸驶入，后车按整车尾部保持间距。新增车流错开既有交通高峰，并使用全部关卡参考桥回归验证承重和通关。

SUV、皮卡、超长重卡和救护车另外完成正面、背面和底部视角渲染检查，确认模型面完整。

## 特种车型二次修订

超长重卡重做为平头牵引车：驾驶室、卧铺区、分隔式前挡风、侧窗、格栅、踏板、后视镜和第五轮连接平台分别建模。挂车底板抬至车轮上方，加强筋中心为2.65m、高2.55m，完整限制在箱体1.25～4.05m范围内，修复原先条纹跨出箱体的问题；增加后门锁杆、反光条、尾灯、后防撞梁和轴杆。当前全车约2880个三角面。

救护车采用独立的驾驶室与高顶医疗舱，不再复用SUV车身模板。前舱使用梯形侧窗和曲面前挡风，医疗舱侧滑门及双开后门分别建模；侧窗、后窗均缩小并限定在对应门板区域，医疗标识置于实心车身面板，与玻璃没有重叠。车顶加入红蓝灯条，医疗舱侧面有腰线，当前全车约1104个三角面。

新增GPU回归检查把无索引自建三角形与带索引基础网格混合合批，确认合并后面数不变且只生成一个合批网格。
