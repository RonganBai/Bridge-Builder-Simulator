# 场景布局与中点连接类型

## 桥面长度

当前玩家回归存档中的8根桥面均为3m，没有被数据模型合并为6m；其中部分中点保存的是6m原构件的刚性父跨度。原构件刚性跨度与单根构件长度是不同概念。

行驶路径按每根桥面的真实端点计算长度，各段分别检查材料最大长度。优先沿实际分段节点依次衔接，避免重叠的长桥面越过中间连接点；即使叠加的6m构件本身合法，也不会替代已有的两段3m路径。超长或过陡的重叠构件同样不会阻挡有效分段路径。回归覆盖3m+3m、叠加合法/超长6m构件、刚性/普通拆分与玩家实际存档。

## 两类中点

- **刚性点**：蓝色方块。保留现有功能，原构件保持直线与固定形状，中点不能独立折叠。适合在原梁上增加连接位置。
- **拆分点**：绿色圆点。原构件变成两根独立构件，中点是可转动的新连接点，可移动并连接支撑；按各自长度计费、检查与受力。构件在该点释放弯矩，联合机构也不会用隐藏刚体约束跨过它。

选择构件后，两种操作分别显示。选择已有蓝色刚性点，可点击“改为拆分点”；同一父跨度中的其他刚性子点会分别归属新点左右两侧，避免仍通过旧父跨度锁住新点。类型、位置和约束支持保存、加载、撤销与重做。

新增连接点本身不是地面支座。两根3m桥面仍需要合理支撑；拆成两段不会凭空提高承重或消除实际失稳。

## 场景细化

每关增加6处住宅、商店和工坊地块，与原有两岸主题地标组成8处建筑区域；城市地标本身还包含多栋楼。补充了门窗、窗台、车库门、店铺雨棚、台阶和封闭山墙屋顶。

建筑、树木、山体和公园共享确定性的占地布局；道路保留至少±4.5m的清空带，建筑模型包围盒必须位于预留地块内，树冠按实际半径避让。山体移至后方，水面扩展到覆盖船只出入区域。已修复悬空集装箱、门架横梁间隙、缺少支腿的栈道、农场门窗重叠和公园长椅占用步道的问题。

建筑与山体使用对应网格的静态碰撞，树干增加碰撞体，供断裂碎片与环境交互。生成场景通过实际渲染、模型占地边界和成对占地相交检查；屋顶、墙体、栏杆等同一物体的正常装配接触不作为穿模。玩家自行搭建的桥梁仍由结构规则约束。

两岸地面和引道延长到100m，覆盖60m列车及超长半挂的完整出场范围，避免车尾尚未进入画面时悬在地形边界之外。岸边建筑和树林仍集中在45m范围，保留道路及建造空间。
